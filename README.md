SMS Spam/Ham Classification for Telco Messaging Gateway

📌 Project Overview

Telecommunication operators process millions of SMS messages daily. A significant portion of these messages are spam, including promotional content, phishing attempts, and fraudulent messages. These messages negatively impact user trust, network efficiency, and regulatory compliance.

This project implements a Machine Learning–based SMS classification system that automatically labels incoming SMS messages as Spam or Ham (Legitimate) before they are delivered through a Telco Messaging Gateway.

🎯 Objectives

Automatically detect spam SMS in real time
Prevent fraud, phishing, and unwanted messages
Improve customer experience and trust
Enable easy integration with telco messaging systems

🧠 Problem Statement

Classify incoming SMS messages into two categories:

📌 What is Ham?

Ham refers to a legitimate, non-spam SMS message that the user actually wants to receive. These messages are usually personal, transactional, or service-related.

Examples of Ham SMS:

“Your OTP for login is 458912.”

“Your bank account has been credited with ₹2,000.”

“Hi, I will call you in the evening.”

“Your order has been delivered successfully.”

🚫 What is Spam?

Spam refers to unwanted, promotional, or fraudulent SMS messages sent without user consent.

Examples of Spam SMS:

“Win ₹50,000 now! Click the link”

“Congratulations! You are selected for a free prize”

The system analyzes SMS text using Natural Language Processing (NLP) techniques and classifies each message as Spam or Ham, enabling the telco gateway to block or allow message delivery.

🏗️ System Architecture

Incoming SMS | v Text Preprocessing | v Feature Extraction (TF-IDF) | v ML Model (Spam/Ham Classifier) | v Decision Engine | ├── Deliver (Ham) └── Block / Flag (Spam)
